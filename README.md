# 스프링 입문을 위한 자바 객체지향 스터디

## 교재

스프링 입문을 위한 자바 객체지향의 원리와 이해

## 진행 방식

- 주 1회 온라인 (목 21:30)
- 매주 정해진 범위를 전원 읽기
- 각자 GitHub에 학습 내용 정리
- 매주 담당 파트를 나눠서 발표
- 발표 후 질문 및 토론
---

## 커리큘럼


| 주차 | 학습 범위 | 주요 내용 |
|---|---|---|
| **Week 1** | **1장 + 2장** | 프로그래밍 언어의 발전 과정, 객체지향이 등장한 배경, JDK/JRE/JVM, T 메모리 구조, Stack Frame, 변수와 메서드, 멀티스레드와 멀티프로세스 |
| **Week 2** | **3장. 자바와 객체 지향** | 객체와 클래스, 추상화와 모델링, 상속, 다형성, 캡슐화 등 객체지향의 핵심 개념 |
| **Week 3** | **4장 + 5장** | abstract, 생성자, static, final, instanceof, interface, this, super 등 자바가 확장한 객체지향 문법 / SRP, OCP, LSP, ISP, DIP 등 SOLID 설계 원칙 |
| **Week 4** | **6장 + 7장** | Adapter, Proxy, Decorator, Singleton, Template Method, Factory Method, Strategy, Template Callback 등 디자인 패턴 / IoC/DI, AOP, PSA와 Spring의 핵심 원리 |
| **Week 5** | **부록 A + 부록 B** | Spring MVC를 이용한 게시판 구축 / Java 8 Lambda와 Interface 스펙 변화 |
