# 스프링 입문을 위한 자바 객체지향 스터디

## 교재

스프링 입문을 위한 자바 객체지향의 원리와 이해

## 진행 방식

- 주 1회 온라인 (목 21:30)
- 매주 정해진 범위 읽기
- 각자 GitHub에 내용 정리
- 당일 담당 파트를 나눠서 설명

---

## 커리큘럼


| 주차         | 학습 범위                        | 주요 내용                                                                        |
| ---------- | ---------------------------- | ---------------------------------------------------------------------------- |
| **Week 1** | **1장. 사람을 사랑한 기술**           | 프로그래밍 언어의 발전 과정, 객체지향이 등장한 배경, 전체적인 학습 방향 잡기                                 |
| **Week 2** | **2장. 자바와 절차적/구조적 프로그래밍**    | JVM, 메모리 구조, 스택 프레임, 변수와 메서드, 멀티스레드와 멀티프로세스                                  |
| **Week 3** | **3장 전반. 자바와 객체 지향**         | 객체와 클래스, 추상화와 모델링, 클래스와 객체의 관계                                               |
| **Week 4** | **3장 후반 + 4장**               | 상속, 다형성, 캡슐화 / abstract, final, static, instanceof, interface, this, super 등 |
| **Week 5** | **5장. 객체 지향 설계 5원칙 - SOLID** | SRP, OCP, LSP, ISP, DIP와 객체지향 설계                                             |
| **Week 6** | **6장 전반. 스프링이 사랑한 디자인 패턴**   | Adapter, Proxy, Decorator, Singleton 등 주요 디자인 패턴                             |
| **Week 7** | **6장 후반. 스프링이 사랑한 디자인 패턴**   | Template Method, Factory Method, Strategy, Template Callback 등               |
| **Week 8** | **7장. 스프링 삼각형과 설정 정보**       | IoC/DI, AOP, PSA와 객체지향 개념이 Spring으로 연결되는 과정                                  |
