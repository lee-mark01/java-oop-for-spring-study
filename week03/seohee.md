# 4장_자바가 확장한 객체지향
## 01_abstract 키워드-추상 메서드와 추상 클래스
추상메서드: 선언부는 있는데 구현부가 없는 메서드 

`일반 메서드 = 메서드 선언 + 구현 / 추상 메서드= 선언 + 구현은 자식 클래스가 해야함`
```java
abstract class 동물{
  abstract void 울어보세요();
  }

  class 쥐 extends 동물{
  void 울어보세요(){
      System.put.println("찍찍");
      }
  }

  class 고양이 extends 동물{
  void 울어보세요(){
      System.put.println("야옹");
      }
  }

  public class Driver{
    public static void main(String[] args){
      동물[] 동물들 = new 동물[2];

      동물들[0] = new 쥐();
      동물들[1] = new 고양이();

      for(int i = 0; i < 동물들.length; i++){
        동물들[i]. 울어보세요();
       }
     }
  }
```
```java
class 동물 {
  void 울어보세요(){
  }
}
```
동물들[0].울어보세요()를 호출하는데 여기서 동물들[0]의 참조변수 타입이 동물이므로 자바 입장에서는 동물 클래스에 울어보세요()는 메서드가 존재해야 함.
따라서 최소한 다음과 같은 메서드가 있어야 한다.
```java
class 동물 {
	void 울어보세요(){
	}
}

class 쥐 extends 동물 {
}
```
- 추상 메서드를 쓰는 이유
1. 자식 클래스가 울어보세요()를 반드시 구현하게 강제할 수 있다.
빈 메서드로 두면 부모의 빈 메서드를 물려받으므로 컴파일 오류가 안 난다. 따라서 개발자가 쥐의 울음소리 구현을 깜빡해도 알 수 없다.	
2. 빈 메서드 방식이면 `동물 a = new 동물();`  도 가능하다. 그런데 추상 클래스로 만들면 오류가 된다. 즉 동물 자체를 객체로 만드는 것도 막아준다.
   
**정리) 기본 동작은 아무것도 안 하는 것으로 하고 자식이 바꾸지 않아도 된다면 { }를 비우고 추상화는 여기서 동작을 정할 수 없고 자식 클래스가 반드시 직접 만들어야 할 때 쓸 수 있다.**

 ## 02_생성자
 `동물 뽀로로 = new 동물();`
 
 생성자 = 객체 생성자 메서드 : 반환값이 없고 클래스명과 같은 이름을 가진 메서드
 
 ```java
public class 동물{
     //public 동물() {}
  }
```
동물 클래스에는 아무런 메서드도 없는 것처럼 보이지만 아무런 인자도 갖지 않는 가본 생성자 메서드가 존재한다.
컴파일 과정에서 자바 컴파일러가 알아서 만들어준다.
```java
new 동물("뽀로로"); // 가능: String 인자를 받는 생성자가 있음
new 동물();         // 오류: 인자 없는 생성자가 없음
```
자바의 특징: 인자가 있는 생성자를 하나라도 만들면 자바는 기본 생성자를 만들어 주지 않는다.

```java
class 동물{
  동물(){
      ````
  }
  동물(String 이름){
      ````
  }
}
```
-> 직접 두 생성자 만들어야함.

 ## 03_클래스 생성 시의 실행 블록, static 블록
 ```java
package staticBlock;
public class 동물{
  static{
    System.out.println("레디");
  }
}
```
```java
동물 뽀로로 = new 동물();
```
결과: 레디

동물 클래스르 사용하는 코드가 있으면 동물 클래스의 static 블록을 실행한다.

(동물 클래스의 인스턴스를 여러 개 만들어도 동물 클래스의 static 블록은 단 한번만 실행됨.)

## 04_final 키워드
클래스, 변수, 메서드에 쓸 수 있다.

- final 클래스
```java
package finalCLass;
public final class 고양이{}
```
상속을 허락하지 않기 때문에 하위 클래스를 만들 수 없음.

- final 변수
```java
package finalVariable;
public class 고양이{
  final static int 정적상수1= 1;
```
변경 불가능한 상수가 됨

- final과 메서드
```java
package finalMethod;
public class 동물{
  final void 숨쉬다(){
```
재정의(오버라이딩)을 금지
