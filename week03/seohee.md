## 03_자바와 객체 지향
### 01_객체 지향은 인간 지향이다
함수란 명령어를 논리적인 단위로 나누어 블록화해서 작성하는 것이다.
  
### 02_객체 지향의 4대 특성 - 캡! 상추다!
1. 캡슐화(Encapsulation): 정보 은닉
2. 상속: 재사용
3. 추상화(Abstraction): 모델링
4. 다형성(Polymorphism): 사용 편의

- 클래스 vs 객체

`클래스 : 객체 = 펭귄 : 뽀로로 //클래스는 분류에 대한 개념, 객체는 실체` 

-클래스를 이용해 object를 만들었다는 것을 강조하고 싶을 때는 **인스턴스(instance)**라는 표현을 많이 씀

### 03_추상화: 모델링
- 추상화란? : 구체적인 것을 분해해서 관심 영역에 있는 특성만 가지고 재조합하는 것 
- 모델링: 추상화의 결과물(클래스로 표현됨)
- **자바는 객체 지향의 추상화를 어떻게 지원하고 있는가? class 키워드를 통새 지원하고 있다**

- `추상화 = 모델링 = 자바의 class 키워드`
  
-논리적 설계: 개발 환경에 영향을 받지 않는 설계

물리적 설계: 개발 환경에 맞춰진 설계
- **클래스 멤버 속성**

```java
public class MouseDriver {
     public static void main(String[] args){
       Mouse.countOfTail = 1;

       Mouse mickey = new Mouse();
       System.out.println(mickey.countOfTail);
  }
}
```
-> static 키워드가 붙은 속성을 클래스 멤버 속성이라고 한다. 
   static 키워드가 안 붙은 속성은 객체 멤버 속성이라고 한다.
(메서드는 클래스 멤버 메서드, 객체 멤버 메서드로 분류)
`클래스 멤버 = static 멤버 = 정적 멤버
 객체 멤버 = 인스턴스 멤버`
-클래스 멤버의 속성: 모든 객체가 같은 값을 가질 때 사용하는 것이 기본
-정적 메서드의 속성: 객체가 없어도 사용 가능
정적 메서드는 언제 사용하는가?
1. main() 메서드 (main()은 프로그램이 시작되는 최초의 진입점이므로 객체가 생성되기 전에도 호출되어야 하기 때문이다.)
2. main() 메서드의 논리를 함수로 분할해서 사용하는 경우
예) ```public class Main {
    public static void main(String[] args) {
        printSum(10, 20);
    }
   
    static void printSum(int a, int b) {
        System.out.println(a + b);
    }
}
```
main()에 모든 코드를 작성하면 복잡해지기 때문에 기능별로 메서드를 나눌 수 있다.
이때 main()이 정적 메서드이므로 여기서 객체 없이 바로 호출하려면 분리한 메서드도 static으로 선언한다.
-정적 속성과 객체 속성의 차이점: 정적 속성은 스택 영역에 클래스가 배치될 때 클래스 내부에 메모리 공간이 할당됨. 반면에 객체 속성은 속성명만 있고 실제 메모리 공간은 할당되지 않고 힙 영역에 객체가 생성되면 메모리 공간 할당됨.

### 04_상속
-객체 지향의 상속은 상위 클래스의 특성을 재사용, 확장하며 is a kind of 관계를 만족해야 한다.

### 05_다형성
오버라이딩(overriding)과 오버로딩(overloading)
-상위 클래스 타입의 객체 참조 변수를 사용하더라도 하위 클래스에서 오버라이딩한 메서드가 호출된다는 점이 중요하다.

``` class Animal {
    void sound() {
        System.out.println("동물이 소리를 냅니다.");
    }
}

class Dog extends Animal {
    @Override
    void sound() {
        System.out.println("멍멍!");
    }
}

Animal animal = new Dog();
animal.sound();
```

결과: 멍멍!
-> 참조 변수는 Animal 이고 실제 객체 타입은 Dog일 때 실행되는 매서드는 Dog의 sound()이며 이것을 동적 바인딩 또는 다형성이라고 함.

### 06_캡슐화
-접근 제어자는 객체 멤버와 쓰일 때와 정적 멤버와 쓰일 때로 나뉨
-상속을 받지 않았다면 객체 멤버는 객체를 생성한 후 객체 참조 변수를 이용해 접근해야 한다.
-정적 멤버는 클래스명.정적멤버 형식으로 접근하는 것을 권장한다. 일관된 형식으로 접근하기 위해서이다. 
-기본 자료형은 실제 값을 복사하고 메서드에서 변경했을 때 원본 변수에 영향이 없고 참조 자료형은 객체의 참조값이 복사되고 같은 객체의 내부 상태는 변경 가능하다.
