# Week 03

## 범위
3장. 자바와 객체 지향

## 학습 내용

### 1. 객체 지향은 인간 지향이다
- **절차적/구조적 프로그래밍의 문제점**: 인간이 기계를 이해하려는 노력에서 벗어나지 못함 (ex. 포인터)
- **함수**: 코드를 논리적 단위로 분할해서 정복 (Divide and Conquer)
- **객체(object)**: 우주 만물은 객체들의 합, 인지 방식대로 프로그래밍 가능 → 직관적
- ex) 클래스(class): 사람 / 객체(object) : 김종민, 한효주, 김연아 / 속성(property) : 나이, 몸무게, 키 / 행위(method): 먹다, 자다, 울다

### 2. 객체 지향의 4대 특성 - 캡! 상추다
- **캡**: 캡슐화(정보 은닉)
- **상**: 상속(재사용) // Inheritance가 아닌 extends
- **추**: 추상화(모델링)
- **다**: 다형성(사용 편의)

### 3. 클래스 vs. 객체
- 붕어빵틀은 붕어빵을 만드는 팩터리 -> 디자인 패턴(6장)
- 펭귄 / 뽀로로 나이 몇 살?
- **클래스**: 개념, 분류 (ex. 펭귄)
- **객체**: 실체, 사물 (ex. 뽀로로)
- 클래스 : 객체 = 펭귄 : 뽀로로

### 4. 추상화: 모델링
- **추상**: 공통 특성/속성 추출
- **추상화**: 구체적인 것을 분해, 관심 영역(애플리케이션 경계)에 있는 특성만 재조합 = 모델링
- **인스턴스(instance)**: 클래스를 이용해 객체를 만들었다는 것을 강조할 때 사용하는 표현
- 속성: 값을 가짐 (ex. 시력, 몸무게, 혈액형) / 메서드: 기능·행위, 수행 절차·로직을 가짐

```java
사람 홍길동 = new 사람();  // 사람이라는 클래스(분류)를 이용해 새로운 하나의 사람(객체)을 만들어 홍길동(객체 참조 변수)이라는 이름을 지어준 것
```

- T 메모리 3대 영역: **스태틱 / 스택 / 힙**
- 클래스와 static 멤버 → 스태틱 영역 배치
- 객체(인스턴스) 생성 시에만 힙 영역에 메모리 할당
- 밑줄 유무로 static(클래스 멤버) / non-static(객체 멤버) 구분

```java
Mouse mickey  // Mouse 객체에 대한 참조 변수 mickey를 만든다
```
Mouse 타입의 객체를 참조할 수 있는 객체 참조 변수 mickey가 T 메모리의 스택 영역 중에서도 main() 메서드 스택 프레임 안에 생성됨

```java
new Mouse()  // Mouse 클래스의 인스턴스를 하나 만들어 힙에 배치한다.
```
객체 생성자를 호출하는 구문. 생성된 객체는 T 메모리의 힙 영역에 배치

대입문  // Mouse 객체에 대한 주소(포인터)를 참조 변수 mickey에 할당한다.
객체 참조 변수 mickey는 Mouse 클래스의 인스턴스를 참조한다.

```java
mickey.name = "미키"
```
객체 참조 변수 mickey 와 참조 연산자(.)를 이용해 실제 힙 상의 객체에 접근해 name 속성에 "미키" 문자열 할당

```java
mickey = null;
```
**가비지 컬렉터**: 아무도 참조하지 않는 객체를 수거 (시점 불명)
Mouse 객체가 사용했던 힙 영역의 메모리 공간 빠짐

```java
Mouse jerry = new Mouse();
```
힙 영역에 있는 Mouse 객체는 이전의 그 Mouse 객체가 아님

- **클래스 멤버(=static=정적 멤버)**: 객체 존재 여부와 무관하게 사용 가능, 스태틱 영역
- **객체 멤버(=인스턴스 멤버)**: 힙 영역, 객체 생성 시 메모리 할당
- 지역변수: 초기화 안 하면 쓰레기 값 / 멤버 변수: 자동 초기화
- 객체 변수: 하나의 객체 안에서 다수의 메서드가 공유 / 클래스 변수: 전역 공유 변수

### 5. 상속: 재사용 + 확장
- **상속(extends)**: 상위 클래스의 특성을 하위 클래스가 재사용·확장
- 상위 클래스(추상화, 일반화) - 하위 클래스(구체화, 특수화)
- 분류도 개념: 하위 클래스 **is a kind of** 상위 클래스 (ex. 펭귄 is a kind of 조류)

```java
animal.showMe();
penguin.showMe();
```
상위 클래스에서만 구현한 메서드를 모든 하위 클래스의 객체에서 사용 가능

```java
동물 animal = new 동물();
동물 penguin = new 펭귄();
```
하위 클래스는 상위 클래스다

- 다중 상속 미지원 → **인터페이스**로 대체
- **인터페이스**: 구현을 강제하는 기능 명세 (구현 클래스 **is able to** 인터페이스)
- 상위 클래스는 물려줄 특성이 풍성할수록, 인터페이스는 강제할 메서드가 적을수록 좋음
- 하위 클래스 인스턴스 생성 시 상위 클래스 인스턴스도 힙에 함께 생성

```java
Penguin pororo = new Penguin();  // 펭귄 한 마리가 태어나니 펭귄 역할을 하는 pororo라 이름 지었다.
Animal pingu = new Penguin();  // habitat 속성과 showHabitat() 메서드 사용 불가
```

### 6. 다형성: 사용편의성
- **오버라이딩**: 같은 이름, 같은 인자 목록으로 상위 클래스 메서드 재정의
- **오버로딩**: 같은 이름, 다른 인자 목록으로 다수 메서드 중복 정의
- 상위 클래스 타입 참조 변수를 사용해도 하위 클래스에서 오버라이딩한 메서드가 호출됨 → 하위 클래스가 무엇인지 신경 쓸 필요 없음

### 7. 캡슐화: 정보 은닉
- 다른 객체의 멤버에 접근하려면 해당 객체를 생성한 후 접근해야 함
- **접근 제어자**
  - public: 모두 접근 가능
  - protected: 상속 / 같은 패키지 내 클래스에서 접근 가능
  - default: 같은 패키지 내 클래스에서 접근 가능
  - private: 본인만 접근 가능
- 정적 멤버는 `클래스명.정적멤버` 형식으로 접근
- 객체 참조 변수 복사 시 **값에 의한 호출 X, 참조(주소)에 의한 호출 O**
